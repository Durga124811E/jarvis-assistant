# Ultron Assistant

A lightweight personal AI assistant for:
- trading research and journaling
- job and earning-platform tracking
- project/task monitoring
- debugging support
- ethical cybersecurity learning
- mobile-friendly browser use

## Requirements

- Python 3.10+
- Flask

## Install

```bash
pip install flask
```

## Run

```bash
python ultron.py
```

Then open:

```text
http://localhost:5000
```

## Notes

- This is a legitimate personal assistant prototype.
- It does not guarantee profits or automate deception.
- For a more realistic custom voice, you can later connect a voice cloning model using your own recorded sample and explicit permission.
- For trading, use only lawful research, journaling, and risk management workflows.
